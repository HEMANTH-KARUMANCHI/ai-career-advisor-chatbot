# AI Career Advisor Chatbot

## Overview
An AI-powered career guidance chatbot that uses a Large Language Model (LLM) to generate personalized career recommendations based on user skills, education, and goals.

## Features
- Personalized career role suggestions
- Skill gap identification
- Learning roadmap generation
- Zero-shot and few-shot prompt engineering

## Tech Stack
- Python
- OpenAI GPT (API-based)
- Prompt Engineering
- dotenv for environment management

## How It Works
1. User provides profile details
2. Input is converted into a structured prompt
3. LLM generates career recommendations

## Limitations
- Depends on prompt quality
- No real-time job market validation
- No persistent user memory
